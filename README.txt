SANTOSH PORTFOLIO & RESOURCE HUB
================================

FILES
-----
index.html
  Complete single-file website: HTML, CSS, and vanilla JavaScript.

RUN LOCALLY IN VS CODE
----------------------
1. Extract this ZIP to a folder.
2. Open the folder in Visual Studio Code.
3. Optional: install the "Live Server" extension.
4. Right-click index.html and choose "Open with Live Server".
   Alternatively, open index.html directly in a browser.

Username: admin

FEATURES
--------
- Login and visitor registration demo
- Admin-only resource controls in the front-end interface
- Add/edit/delete resource entries
- Search and category filters
- Dark/bright theme toggle
- Responsive design and 3D-style animations
- Browser localStorage for resource entries and demo users

IMPORTANT LIMITATIONS
---------------------
This is a front-end demo, not production-secure authentication.
Admin credentials and client-side logic are visible in index.html.
Accounts and resource metadata are stored in the current browser only.
Local file URLs are temporary and are not shared with other visitors.
For a public website with real privacy and admin-only permissions, add
server-side authentication, a database with access rules, and cloud file
storage. Do not use this demo to protect sensitive resources or accounts.

CUSTOMIZATION
-------------
Open index.html and search for:
- ADMIN_USERNAME and ADMIN_PASSWORD: demo admin credentials
- CONTACT_EMAIL: contact form email address
- seed: sample resource cards
- Portfolio text and project cards: personal content
