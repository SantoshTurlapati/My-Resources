# My-Resources
# 🚀 Santosh Portfolio Resource Hub

A modern, colorful, and responsive portfolio website where visitors can explore and download study materials, PDFs, notes, project repositories, and certificates — all in one place.

## ✨ Features

- 🎨 **Modern UI:** Colorful design with 3D effects and smooth animations.
- 🌙 **Dark & Bright Mode:** Switch between dark and light themes.
- 🔐 **Login & Registration:** Demo user authentication interface.
- 🛠️ **Admin Dashboard:** Add, edit, and delete learning resources.
- 📚 **Resource Library:** Organize PDFs, notes, projects, and certificates.
- 🔍 **Search & Filter:** Find resources quickly by name or category.
- 📥 **Download Support:** Access available resource files.
- 📱 **Responsive Design:** Works on desktops, tablets, and mobile devices.
- 💾 **Local Storage:** Save demo resources and user information in the browser.

## 🖥️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ⚙️ How to Run the Project

### Option 1: Open in a Browser

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website opens in your default browser.

### Option 2: Run Using VS Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

- Add new resources and links.

## ⚠️ Current Limitations

This version is a frontend demo intended for learning and portfolio purposes.

- Data is stored in browser Local Storage.
- Data is not automatically shared between different users or devices.
- Local file selections may not remain available after refreshing or reopening the page.
- Authentication and admin access are not secure enough for production.
- A backend and cloud file storage are required for persistent, shared resource hosting.
